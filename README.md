# Aurora

macOS·Windows를 목표로 만드는 AI 데스크톱 작업 공간입니다.
Codex의 사이드바·대화·입력창 구조를 참고하고 잔여 사용량을 더 쉽게 읽도록 구성했습니다.
현재는 **로컬 UI 프로토타입**입니다. Codex의 전체 기능을 복제한 앱은 아닙니다.
원래 Chrome 확장 기획은 `readme`에 보존합니다.

## 시작하기

Node.js 24 환경에서 저장소 루트에서 실행합니다. 개발 빌드·QA는 외장 SSD를 검증하는 `./dev`를 거칩니다.

```bash
./dev npm ci
./dev npm start
```

웹 서버를 열지 않고 빌드한 화면을 Electron의 `aurora://app` 프로토콜로 표시합니다.
별도 API 키나 로그인이 필요하지 않습니다.

## 구현한 범위

- 대화 생성·전환·검색, 입력창, 모델 등급 선택, 사이드바와 사용량 패널 토글
- 5시간·주간 한도의 **샘플** 잔여 비율과 초기화까지 남은 시간
- 샘플을 끈 경우 미연결 표시: 확인되지 않은 잔여량을 0%나 100%로 간주하지 않음
- 질문의 단어·길이를 이용한 로컬 추천 미리보기. 실제 AI가 질문을 수행하지 않음
- 라이트·다크 테마, 선택적 로컬 대화 저장 (기본 꺼짐)
- Node 접근 차단, renderer sandbox·context isolation, 외부 연결·탐색·새 창 차단

모델 등급 선택은 대화에 기록됩니다. 아직 실제 제공자나 실행 모델을 선택하지 않습니다.
테마와 샘플 표시 설정은 현재 창에만 적용됩니다. 대화 저장을 끄면 저장 사본은 삭제되고 현재 창의 대화는 유지됩니다.
실제 한도, 모델명, 토큰 비용, 성공률, 계정 연결을 추정해 표시하지 않습니다.

## 검증

```bash
./dev npm run build
./dev npm test
./dev npm run test:desktop
```

데스크톱 QA는 설치된 Electron만 실행합니다. 별도 Chrome 세션이나 웹 서버를 만들지 않습니다.
QA 프로필은 `<build-volume>/tmp/aurora-qa-*`, 화면 캡처는 Git에서 제외한 `artifacts/`에 둡니다.
macOS에서 실행 검증했으며 Windows 실행·설치 프로그램·코드 서명·공증·자동 업데이트는 후속 작업입니다.
