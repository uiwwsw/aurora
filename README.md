# Aurora

macOS·Windows를 목표로 개발하는 AI 데스크톱 작업 공간입니다.
현재는 **오프라인 워크플로 프로토타입**으로, 실제 AI 응답·계정 연동은 아직 없습니다.
원본 Chrome 확장 기획은 `readme`에 보존합니다.

## 시작하기

Node.js 24에서 외장 SSD 빌드 환경을 검증하는 래퍼를 사용합니다.

```bash
./dev npm ci
./dev npm start
```

웹 서버 없이 `aurora://app`으로 로컬 화면을 엽니다. API 키나 로그인이 필요하지 않습니다.

## 두 가지 대화 모드

기본 **자동 정리 모드**는 하나의 연속된 대화입니다. 새 세션 버튼이 없고 사용자는 계속 입력합니다.
현재는 키워드와 명시적 주제 전환·완료 표현으로 정리가 필요한 지점을 감지합니다.
실제 AI 판단이 아닌 **로컬 규칙**임을 UI에 표시합니다.

다음 요청 검토 창에서 이전 작업을 **묶기 / 버리기 / 보관하기 / 계속 이어가기** 중 선택합니다.
선택만으로 데이터를 변경하지 않고, 진행을 확인할 때 적용합니다. 취소하면 원문과 작업 상태를 유지합니다.
버리기는 영구 삭제가 아닌 휴지통 이동이며 보관함·휴지통에서 복원할 수 있습니다.
묶거나 보관하거나 버린 작업은 다음 요청의 추정 문맥에서 제외합니다.
복원된 작업은 묶음으로 돌아오며 새 요청의 문맥에 자동 포함하지 않습니다.

설정의 **레거시 모드**에서는 사용자가 세션을 만들고 전환하며 자동 정리 제안을 하지 않습니다.
두 모드의 대화는 독립적으로 유지됩니다. 모드 전환으로 데이터를 삭제하거나 합치지 않습니다.
이전 버전의 다중 세션 기록은 레거시 세션으로 읽습니다.

## 전송 전 모델과 소모량 검토

1. 입력 내용으로 모델 **등급**과 이유를 제안합니다. 실제 제공자 연결 전에는 구체적인 모델명을 확정하지 않습니다.
2. 입력과 현재 문맥, 모델 등급별 출력 가정으로 입력·출력·합계 토큰 범위를 표시합니다.
3. 사용자가 모델 등급을 바꾸면 예상 출력과 합계를 다시 계산합니다.
4. 직접 설정한 **계획용 토큰 예산**이 있으면 그 예산 대비 %를 표시합니다.
5. 실제 계정 한도 대비 %는 **추정 불가**로 표시합니다. 잔여 비율만으로 토큰을 임의 환산하지 않습니다.

토큰 계산은 문자 수 기반 근사치이며 실제 토크나이저·추론·도구 호출·재시도 비용을 반영하지 않습니다.
실행 버튼도 현재는 **로컬 미리보기**입니다. 질문을 AI가 수행하거나 실제 한도를 차감하지 않습니다.
실제 계정 잔여량은 미연결 상태이며 예전 샘플 퍼센트는 제거했습니다.

## 데이터와 보안

대화 저장은 기본 꺼짐입니다. 설정에서 켜면 두 모드의 기록·모드·계획 예산을 이 기기에 저장합니다.
끄면 저장 사본은 제거하고 현재 창의 대화는 유지합니다. 테마는 현재 창에만 적용합니다.
renderer Node 접근은 끄고 sandbox·context isolation을 사용합니다. 외부 네트워크·탐색·새 창·권한 요청을 차단합니다.

## 검증

```bash
./dev npm run build
./dev npm test
./dev npm run test:desktop
```

데스크톱 QA는 설치된 Electron을 SSD의 독립 프로필로 실행하며 별도 브라우저·웹 서버를 만들지 않습니다.
QA 프로필은 `/Volumes/DevBuild/tmp/aurora-qa-*`, 스크린샷은 Git 제외된 `artifacts/`에 남습니다.
macOS에서 검증했습니다. Windows 실행·설치 패키지·서명·공증·자동 업데이트는 아직 검증하지 않았습니다.
