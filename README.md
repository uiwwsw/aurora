# Aurora

작업 범위와 예상 토큰을 검토한 뒤 실행 여부를 결정하는 데스크톱 AI 작업 공간.
이름은 *Auto Router · Low AI*에서 가져왔습니다.

**v0.1.0 · 로컬 프로토타입 · MIT**

![Aurora 작업 공간](docs/images/aurora-v0.1.png)

## 소개

Aurora는 AI에게 작업을 맡기기 전에 요청의 범위, 사용할 모델, 예상 소모량을 확인하는 흐름을 실험합니다.
하나의 대화에서 작업을 이어가고, 정리가 필요하면 이전 내용을 묶거나 보관합니다.
세션을 직접 관리하는 레거시 모드도 제공합니다.

현재 추천과 정리는 로컬 규칙으로 동작합니다. 실제 모델 호출과 계정 사용량 연동은 아직 구현하지 않았습니다.

## 기능

- 하나의 대화 흐름과 작업 묶음
- 주제 전환·완료 표현을 이용한 정리 제안
- 묶기·보관·휴지통·복원
- 직접 세션을 생성하고 전환하는 레거시 모드
- 전송 전 모델 등급과 예상 입력·출력 토큰 검토
- 계획용 토큰 예산 대비 비율 표시
- 대화 검색, 선택적 로컬 저장, 라이트·다크 테마

모델 추천은 경량·표준·고성능 등급 기준입니다. 실제 모델을 자동으로 선택하거나 요청을 수행하지 않습니다.

## 토큰 추정의 범위

현재 화면의 토큰 수는 문자 수와 모델 등급별 출력 가정으로 계산한 근사치입니다. 실제 측정값이나 완료에 필요한 토큰의 견적이 아닙니다.
계획용 예산의 %는 사용자가 입력한 토큰 예산 대비 비율이며, 구독 한도의 %가 아닙니다.

실제 모델 연결 시에도 입력 토큰 계산과 전체 작업량 예측은 다릅니다. 출력·추론·도구 호출·재시도량을 사전에 확정할 수 없으며, 출력 상한을 설정하면 작업이 끝나기 전에 응답이 중단될 수 있습니다.
계획을 만드는 AI 호출 자체도 토큰을 사용하므로 본 작업과 별도로 관리해야 합니다.

향후에는 작업을 작은 단계로 나누고 완료 조건을 확인하며, 예산을 추가하기 전에 다시 승인받는 흐름을 검토합니다.
**정해진 토큰으로 정해진 기능의 완성을 보장하지 않습니다.** 현재는 예산 강제 제한도 구현하지 않았습니다.

관련 설계와 근거는 [실행 예산 설계](docs/product-vision.md)에 정리했습니다.

## 실행

Node.js 24 이상과 npm이 필요합니다.

```bash
git clone https://github.com/uiwwsw/aurora.git
cd aurora
npm ci
npm start
```

Electron + React + TypeScript로 구성되어 있으며 별도 웹 서버 없이 실행합니다.
현재 버전에는 API 키나 로그인이 필요하지 않습니다. 설치 프로그램은 아직 제공하지 않습니다.

## 개발

```bash
npm run build          # 타입 검사 및 프런트엔드 빌드
npm test               # 도메인 로직 테스트
npm run test:desktop   # Electron UI 테스트
```

macOS·Windows CI에서 빌드와 단위 테스트를 검증합니다. 데스크톱 UI는 macOS에서 검증했으며 Windows 앱 실행과 패키징은 아직 미검증입니다.
관리자의 SSD 개발 환경에서는 npm 명령 앞에 `./dev`를 사용합니다.
